# 钉钉 AI Card 流式回复

钉钉默认使用 Markdown 发送完整回复。启用 AI Card 后，FastClaw 会在回答生成时更新同一张卡片；卡片创建、更新或结束失败时会自动回退为一条完整 Markdown 消息。

## 配置

在钉钉连接窗口选择 **AI Card — stream answer**，并填入已在该钉钉应用中发布的卡片模板 ID。更新频率默认是 1000ms，最小 200ms。

模板必须至少提供 `content` 字符串字段和可显示完成状态的字段。请在钉钉开放平台为该应用创建、发布模板并授予 AI 卡片相关权限；模板 ID 不能跨应用假定可用。

Markdown 仍是默认并支持标题、列表、链接、代码和图片。表格会被转换为文本以避免钉钉客户端的 GFM 表格渲染差异。
